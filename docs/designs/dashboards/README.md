# Dashboards

After working on the previous user [dashboard prototype](../prototypes/images/03%20-%20User%20dashboard%20page.png) I decided that it's not really the direction I want to go. I didn't like all of the multiple same-sized "decks" that a user may have. There was no priority. What if the user had only 1 deck? There'd be too much whitespace.

I asked 5 different AIs to create an example dashboard image. I sent these 5 to several people. The most popular was [example-02](./example-02.png). Here's what I like about each one:

1. [example-01](example-01.jpeg): big font, big buttons, two CTAs (Start Review & Learn new words), and the current deck, or perhaps the deck that has the most cards due today, is larger in size and more prominent
2. [example-02](example-02.png): great user welcome message, language switcher at the top-right, very prominent active deck, nice layout, and the study tip
3. [example-03](example-03.png): the daily goal + days of the week streak, your memory card
4. [example-04](example-04.png): today's plan card, prominent active deck card
5. [example-05](example-05.jpg): colors easy on the eyes (but perhaps not good for the color blind), language switcher, saperate review from new words
