## Changes

Some major changes from the wireframe include:

**1. Added a Typing Test to the Study Session.**

* This is to reflect the idea of the "front" of a flashcard and give the user a chancel to recall.
* In this example the user is expected to test their knowledge by typing out the word.
* The user automatically moves to the next screen upon their answer, or if they chose to skip the word or reveal the answer.
* Pausing the session sends the user back to the Dashboard.

**2. Added a Listening Test Study Session.**

* In this example the user is expected to test their knowledge by typing out the word they hear.

**3. Updated the Study Session's answer screen.**

* Removed the "Anki-styled" buttons.
* In this example the user answered the previous screen's test correctly.

**4. Added a Final screen to the Study Session.**

* This screen is shown when the user has completed their study session.
* The user is given a couple of options on how they'd like to proceed.

**Besides the interactivity of the other changes were minimal:**

* copy enhanced
* footer improved
* better general layout
